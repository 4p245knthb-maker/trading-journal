      Synchronisation entre appareils (GitHub Gist)

      Sauvegarde tes données (trades, objectifs, réglages) sur un Gist GitHub privé pour les retrouver sur ton MacBook, ton PC du travail et ton téléphone.

      Aucune synchronisation effectuée.

      Comment faire (une seule fois par appareil)
      1. Sur github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → crée un token avec la permission Gist uniquement (lecture/écriture).
      2. Colle ce token ici sur ton MacBook, puis clique « Envoyer vers le cloud » — un Gist privé est créé et son ID s'affiche automatiquement.
      3. Note cet ID. Sur ton PC du travail ou ton téléphone, colle le même token + le même ID, puis clique « Récupérer depuis le cloud ».
      4. Après chaque session de trading, clique « Envoyer » sur l'appareil que tu viens d'utiliser pour garder tout à jour partout.
      Sauvegarde manuelle (sans compte GitHub)

      Alternative simple : exporte un fichier de sauvegarde et importe-le sur un autre appareil (AirDrop, email, clé USB...).
